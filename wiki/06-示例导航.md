### 3.6 神经网络代理模型（数据驱动建模）

这两个示例演示「**把训练好的 ANN 当作被控对象模型**」——与 `CSTR_approximate_mpc`（ANN 当控制器）方向相反。完整原理见 [09 · 循环网络与自定义算子扩展](09-循环网络与自定义算子扩展.md)。

#### `ann_surrogate_model/` — 前馈网络代理模型

| 项 | 内容 |
|---|---|
| 模型 | 离散，2 状态（位置/速度）、1 输入；网络 3→32→32→2，`tanh` 激活 |
| 流程 | 训练 FFN → **手工提取权重翻译成 CasADi** → `model.set_rhs` → MPC 闭环 |
| 亮点 | ① 四层验证（CasADi vs PyTorch、`_rhs_fun` 逐位一致、autodiff vs 解析雅可比、稳态映射）<br/>② 实测**归一化的决定性影响**：不归一化 → 相对误差 53%、稳态映射符号反转；归一化 → 0.6%<br/>③ 与机理模型（CVODES 精确积分）并行对比 |
| 实测 | 跟踪误差 `1.07e-05`，稳态力 `0.04989` vs 解析 `k·sp = 0.05`，单步 `19.5 ms` |
| 文件 | `main.py`（自包含） |
| 依赖 | `torch` |

#### `lstm_surrogate_model/` — LSTM 代理模型 ⭐

| 项 | 内容 |
|---|---|
| 模型 | 离散，**33 状态**（1 观测 + 16 `h` + 16 `c`）、1 输入 |
| 场景 | 质量-弹簧-阻尼系统，**代理模型只观测位置**，速度必须靠 LSTM 隐状态从历史推断 —— 正是循环网络有价值的场景 |
| 核心范式 | **cell 化 + 隐状态入 `_x`**：MPC 的时域展开 = LSTM 的时间展开 |
| 亮点 | ① `main.py`：训练 → 手工翻译 → MPC 闭环 + 四层验证<br/>② `onnx_path.py`：ONNX 路线，并证明与手工路径**逐位等价**（`rhs_fun` 差 `2.22e-16`，8 步 MPC 控制量差 `0.00e+00`）<br/>③ 对比原生转换器在 `RNNCell` / `LSTMCell` / 序列 `LSTM` 上的能力边界<br/>④ **part 4**：用 `do_mpc.sysid.ann_to_dompc_model` 声明式构建同一模型（6 行 spec 替代 ~25 行手工接线），演示 LSTM→GRU 只改 spec、错误 spec 被前置拦截 |
| 实测 | 跟踪误差 `3.27e-07`，稳态力 `0.05041` vs `0.05`，单步 `287 ms`，`opt_x = 543` |
| 文件 | `main.py`, `onnx_path.py` |
| 依赖 | `torch`；`onnx_path.py` 另需 `onnx` |
| 回归测试 | [`testing/test_lstm_surrogate_model.py`](../testing/test_lstm_surrogate_model.py)（6 个）、[`testing/test_ann_to_model.py`](../testing/test_ann_to_model.py)（61 个）、[`testing/test_onnx.py`](../testing/test_onnx.py)（106 个） |

> ✅ [`examples/tools/onnx_conversion/`](../examples/tools/onnx_conversion) 下的两个脚本已修复：改用 `tf2onnx.convert.from_keras` 显式导出后传给 `do_mpc.sysid.ONNXConversion`（该接口只接受 `onnx.ModelProto`，**没有** `from_keras` 参数）。实测与 Keras 预测的最大偏差分别为 `5.73e-08` 与 `1.01e-07`。

## 五、运行示例的注意事项

### 1. 工作目录

示例脚本用相对路径 `os.path.join('..','..')` 定位 do-mpc，因此**必须在示例目录内运行**：

```bash
cd examples/CSTR
python main.py          # ✅
# python examples/CSTR/main.py   # ❌ 可能找不到模块
```

### 2. 交互式阻塞

多数 `main.py` 结尾有：

```python
input('Press any key to exit.')
```

在 CI 或非交互环境下需要去掉或喂入换行。

### 3. 动画开关

```python
show_animation = True    # 改成 False 可大幅加速（不做实时绘图）
store_results  = False   # 改成 True 会写入 ./results/*.pkl
```

### 4. 求解器输出

第一次运行时 IPOPT 会打印大量迭代日志。这是**有用的诊断信息**，建议先看一下确认收敛；生产环境再用 `mpc.settings.supress_ipopt_output()` 关掉。

### 5. 后端问题

Windows 上如果动画窗口弹不出来，参考 `CSTR_approximate_mpc/main.py` 里的做法：

```python
import matplotlib
matplotlib.use("TkAgg")
```
